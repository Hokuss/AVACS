01. About Me

Hello! I'm Gyanam Modi, a software engineer deeply passionate about low-level programming, graphics architectures, and systems security. I thrive on understanding how software interacts with hardware at the lowest levels.

My core journey revolves around modern C++ (C++17/20), crafting real-time graphics applications with OpenGL, GLFW, GLEW, and ImGui. I build custom shader pipelines, interactive UI debug overlays, and modular engine architectures.

Additionally, I have a strong fascination with Reverse Engineering & Security Analysis Tools. Whether it's dissecting binaries, analyzing memory structures, or configuring cross-platform MSYS2 toolchains, I love tackling complex backend and systems-level challenges.
